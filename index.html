Aide rapide

1) Sur roboflow.com, crée un projet de type « Object Detection » (pas « Classification »), importe tes photos de gravier/terrasse et dessine un rectangle autour de chaque mauvaise herbe visible, avec le même nom de classe à chaque fois (ex. mauvaise_herbe). 2) Clique « Generate » puis « Train » pour entraîner le modèle (gratuit). 3) Dans l'onglet « Deploy » du projet entraîné, récupère l'ID du projet, le numéro de version et ta clé API (Settings → API Keys de ton espace de travail), et colle-les ci-dessus. 4) Clique « Démarrer la caméra » et autorise l'accès à la caméra. Cette page a besoin d'internet pendant la démo (elle envoie une image toutes les ~0,6 seconde à Roboflow) — elle ne fonctionne pas hors-ligne, contrairement à la version simple sans carrés.

La clé API est visible dans le code source de la page une fois publiée sur GitHub — sans enjeu pour un projet scolaire, mais à savoir si tu publies ce dépôt publiquement.
